PRIVACY · BETA 0.2.0

Direct by design.

DKP has no account, analytics service, advertising system or answer database.

What is sent

Only after you run an AI action, DKP sends the relevant extracted page blocks, task text, choices, selected context excerpts, preferences, and any text or image you explicitly attach to the AI provider selected in Settings. Website content can contain personal or confidential information, so review the page before generating.

Where it goes

Requests go directly from Firefox to Google Gemini, OpenAI, Anthropic Claude or DeepSeek. DKP does not proxy or copy them through a DKP server. Each provider processes the request under its own API terms and data policy.

API keys

A key is sent only to its provider for authentication. Session storage is the default. “Remember on this device” stores it in the local Firefox extension profile, which is not an encrypted secrets vault. Keys are removed from visible errors and are never inserted into the learning page.

Contexts

Context names and extracted page knowledge stay in Firefox extension storage on this device. A context keeps at most 12 compact page snapshots. Deleting a context removes those local snapshots. DKP does not sync them between devices.

What DKP avoids

DKP does not deliberately collect cookies, passwords, Moodle session tokens, hidden form values or existing draft answers. It does not submit quizzes. It does not execute code returned by an AI provider.

Media and documents

Embedded videos, audio and linked documents are not automatically opened. DKP warns only when a particular task appears to require unavailable material.

Your controls

Forget provider keys in Settings, remove individual pages, delete whole contexts, or uninstall DKP to clear extension storage.
